# dilatR (jour 3)

Package R : matrices de dilatation et joints de pont.

1.  Ouvrir `dilatR.Rproj` dans RStudio.
2.  Remplacer Prenom / Nom / e-mail dans `DESCRIPTION`, puis :
    `usethis::use_mit_license("Prenom Nom")`
3.  `source("data-raw/materiaux.R")`
4.  `devtools::document()` puis `devtools::load_all()`
5.  `devtools::test()` puis `devtools::check()`

Le guide PDF du jour 3 detaille chaque etape.
